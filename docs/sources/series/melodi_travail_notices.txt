===== DD_EEC_SERIES =====
Titre : Activité, emploi et chômage - séries longues
Sous-titre : Enquête Emploi en Continu
Périodicité : Annuel
Couverture : 1975-01-01 - 2025-01-01 ; spatial : FE ; niveaux : FRANCE
Mise à jour : 2026-05-13
Description :
Les données sont détaillées par sexe, âge, diplôme et catégorie socio-professionnelle (PCS). Pour l’emploi, les données sont détaillées par type de contrat, composante du sous-emploi, temps de travail (temps complet ou partiel). Plusieurs indicateurs en taux sont disponibles : taux d'activité, taux d'emploi ou taux de chômage. 

Ce jeu de données regroupe notamment les données annuelles de forte valeur (High Value Dataset ou HVD statistiques) désignées par Eurostat sur les sujets suivants : l'emploi , le chômage et la main d’œuvre potentielle.

===== DS_SRCV_SATISFACTION =====
Titre : Conditions de vie : niveau de satisfaction
Sous-titre : Enquête statistiques sur les ressources et les conditions de vie (SRCV)
Périodicité : Annuel
Couverture : 2010-01-01 - 2025-01-01 ; spatial : FEHM ; niveaux : FRANCE
Mise à jour : 2026-09-29
Description :
Données annuelles sur la satisfaction subjective des personnes. Sur une échelle allant de 0 (pas du tout satisfait) à 10 (entièrement satisfait), la satisfaction est évaluée dans trois domaines : la vie en général, les relations sociales, le travail. Ces indicateurs sont notamment déclinés selon le sexe, l'âge, le niveau de vie du ménage, le diplôme, la profession et catégorie socio-professionnelle (PCS), la situation vis-à-vis de l'emploi, la nationalité, la composition de la famille, le statut d'occupation du logement, l'indicateur de limitation d'activité générale, la note donnée à l'état de santé en général et le nombre de difficultés matérielles rencontrées dans le ménage.

===== DS_DERA_PRIVE_SERIES_LONGUES =====
Titre : Séries longues de salaires dans le secteur privé
Sous-titre : Base Tous salariés (BTS)
Périodicité : Annuel
Couverture : 1951-01-01 - 2024-01-01 ; spatial : FE ; niveaux : FRANCE
Mise à jour : 2025-12-04
Description :
Les séries longues de salaires sont ventilées par sexe, secteur d'activité, catégorie socioprofessionnelle, tranche d'âge et temps de travail. En plus de la moyenne, plusieurs statistiques sur la distribution des salaires sont disponibles.  Les salaires peuvent être exprimés en euros constants, en indice base 100 en 1996 ou en évolution en euros constants par rapport à l'année précédente. 
Champ : France depuis 2000, France métropolitaine jusqu'en 1999, salariés du privé, y compris alternants, stagiaires et bénéficiaires de contrats aidés ; hors salariés de l'agriculture et salariés des particuliers-employeurs.
Ces données peuvent également être consultées dans l'outil de datavisualisation sur les salaires
