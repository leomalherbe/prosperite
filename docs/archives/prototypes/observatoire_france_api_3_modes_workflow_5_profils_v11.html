Poids internes normalisés
Bornes par défaut : borne basse à −50 % et borne haute à +50 % autour de la dernière valeur observée disponible. Les deux poignées occupent ainsi la même position initiale sur toutes les barres (25 % et 75 %). Elles seront remplacées par le socle méthodologique de référence lorsque celui-ci sera défini. Les valeurs observées proviennent toujours de l’API.
